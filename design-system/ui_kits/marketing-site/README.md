# Marketing site — Sifu

One-page marketing site. Generous negative space, hairline rules, single indigo accent.

## Components
- `Header.jsx` — wordmark + spare nav
- `Hero.jsx` — eyebrow, statement, sub, CTA
- `WhatItDoes.jsx` — three quiet steps, mono numerals
- `SamplePanel.jsx` — preview of an actual classification report (ties to product UI)
- `CaseList.jsx` — written cases / "lessons" (the teaching mode)
- `Pricing.jsx` — two plans, one indigo seal, no exclamation marks
- `Footer.jsx` — wordmark, mono links, the seal

## Index
`index.html` composes all of the above into the full one-pager.
